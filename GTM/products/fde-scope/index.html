CHECKLIST · 清单

A record. Freshest the day it is filled in, then it rots as reality drifts: the box never learns the world changed.一份记录。填完那天最准，此后随现实漂移单向腐化，勾选框不会知道世界变了。

GATE · 门禁

A predicate. Re-run on every advance; a stale pass never counts. Even force evaluates and records, so the override itself stays on the audit log.一个谓词。每次推进重新执行，过期通过一律不作数；强推也照常评估留痕，例外本身进审计。

03Best practices

最佳实践 · 六条不变式

  • Live gate re-evaluation每次 advance 重评门禁，过期 passed 不放行
  • Server-generated IDs外部输入永远不能指定记录 ID
  • Credentials env-only密钥只走环境变量，绝不落 manifest/报告/日志
  • Atomic writes所有落盘记录经 fsutil.atomic_write_text
  • Rule grants only唯一权限通道；未匹配工具 DEFAULT→ASK · DONT_ASK→DENY
  • Measured AgentScope window>=2.0.4.post1,<3 逐版本实测，契约测试钉住引用
