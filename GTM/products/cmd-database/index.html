单一数据源，三条命令入库

每条命令在 tools/cmd/data/*.yaml 定义一次，Wiki、双向链接与 CLI 索引全部由此生成。

tools/cmd/data/ai/llm-training.yaml
category: "AI基础设施/大模型训练"
commands:
- name: deepspeed
  description: "微软DeepSpeed大规模分布式训练框架…"
  usage: ["deepspeed [OPTIONS] SCRIPT.py [ARGS...]"]
  options:
  - flag: "--num_gpus"
    description: "使用的GPU数量"
  examples:
  - command: "deepspeed --num_gpus=4 train.py --deepspeed ds_config.json"
  related_commands: [accelerate, torchrun]
  risks:
  - level: medium
    description: "大规模分布式训练消耗大量GPU资源…"
  1. 编辑 YAML在对应领域文件里新增或修改命令定义。tools/cmd/data/<领域>/<文件>.yaml
  2. 校验schema、链接与风险等级自动检查。go run ./cmd/validator -d ./data -v
  3. 生成语料重新生成带双向链接的 Markdown 页面。python3 tools/cmd/scripts/wiki/convert_to_wiki.py
