SEC.01EXECUTIVE SUMMARY

执行摘要先说结论 —— 本方案的一切动作，服务于一个北极星

一句话定位：《孤裂》是一部中文原创心理恐怖长篇——以"一米五的距离"为刀， 把"爱即囚禁"写进一个被 372 张电影海报封死的透明盒子。首发微信读书，以口碑 + 议题双引擎破圈， 走"电子首发 → 实体出版 → 有声 / 短剧"的 IP 路径。

判断 / 01

品类空位真实存在

心理恐怖在中文图书市场长期依赖翻译引进（斯蒂芬·金、日系恐怖）。国产原创、文学性过硬的心理恐怖长篇供给稀缺——读者被喂养多年，但选择很少。

判断 / 02

超级意象自带传播性

"372 张海报封死的阳光房""一米五的距离""别吵，她刚睡着了"——这些是天然的记忆钩子，可直接转译为概念海报、短视频与金句物料，不需要发明营销话术。

判断 / 03

议题性是双刃剑

家暴与控制型亲密关系是高敏感社会议题：既是流量入口，也是审核与舆情风险。全案以"批判控制之爱"为统一叙事口径，联动公益，绝不浪漫化。

北极星指标
NORTH STAR

30 日完读率 ≥ 55% —— 恐怖文学的全部商业逻辑都建立在"读完并后背发凉"的人身上：完读催生书评，书评催生下一批读者。所有渠道、物料、节奏，皆为把读者送完最后一章。

SEC.02MARKET & CATEGORY

市场与品类我们不在红海里抢份额，我们在空位里定义品类

品类选择：心理恐怖 × 社会派悬疑。明确不做两件事——不做灵异驱魔的"鬼故事"， 也不做短平快的网文爽文。本书的恐怖来自人性与空间，竞争帧应锚定在"严肃类型文学"而非"网络小说"。

三个市场事实

① 悬疑推理是中文电子阅读最稳定的常青品类。微信读书、豆瓣阅读的畅销与榜单长年由悬疑推理占据， 读者付费意愿明确、书评文化成熟，天然适合口碑型冷启动。

② 国产悬疑的受众已被影视教育完成。从《白夜行》到《隐秘的角落》《漫长的季节》， 过去十年完成了大规模的"国产悬疑受众训练"——他们能欣赏慢热、隐喻与道德灰度，正是本书的目标土壤。

③ 心理恐怖赛道几乎全靠引进。书店与平台的"恐怖"货架被欧美翻译作品占据， 中文原创长期缺位。空位：一部"为影迷写的中文恐怖小说"——《闪灵》《着魔》《2001 太空漫游》的互文是现成的锚点， 直接向影迷群体心智借力。

SEC.04POSITIONING & MESSAGING

定位与信息一座信息屋：一个屋顶，三根支柱，一堆证据

定位声明（Positioning Statement）：对于想被"缓慢渗透的恐怖"击中的成熟读者， 《孤裂》是一部中文原创心理恐怖长篇，它把"保护"写成"囚禁"—— 因为你读过的恐怖来自鬼怪，而它来自爱。

核心信息 · CORE MESSAGE
"你保护一个人，
却成为囚禁她的人。"
支柱 / 壹

空间即恐怖

三层别墅是一套象征语法：一楼是腐朽的地基，二楼是表象的秩序，三楼是透明的囚笼。"一米五"是全书的道德阈值——一步之遥，生死之隔。

支柱 / 贰

工程师式冷感

第一人称、克制、精确到残忍。他计算风速与房屋结构，"我知道如何让一个人消失——不是靠暴力，靠设计"。理性与疯狂只隔一张图纸。

支柱 / 叁

缓慢渗透的恐怖

没有 jump scare。铁锈味、墙后的呼吸声、海报的温热——恐怖从感官缝隙里渗进来，读完后才在后背合拢。

"别吵，她刚睡着了。" "你懂得如何建造，也懂得如何摧毁。" "疼痛是其中一种方式。" "我本来想给你也做一枚。"

统一口径（所有对外发声必读）

✓ 这样说：这是一部批判控制型爱的作品——"保护即囚禁"是它的判词，不是它的糖。 讨论家暴、沉默与共谋，是我们主动选择的议题责任。

✗ 绝不说：不使用"病娇""虐恋""窒息感爱情"等浪漫化标签；不做"为爱藏起一个人"的猎奇化表达； 不在未经内容审校的渠道释放涉家暴细节的原文片段。
