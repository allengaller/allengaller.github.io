01 · 为什么是孤独世界

你读过一百个结局，
还没读过只属于你的那一个

在 AI 之前，我们只能在别人写好的故事里打卡。现在，故事终于可以由你执笔——但大多数 AI 玩法，都弄丢了三样东西。

PAIN — 01

传统文字冒险：剧本是写死的

再厚的分支树也是有限的。二周目开始，你看到的不是故事，是攻略。通关即弃，没有第二次新鲜感。

PAIN — 02

直接和聊天 AI 扮演：转身就忘

有求必应，但关掉窗口什么都不剩：没有存档、没有世界、没有积累。上次的恩怨，这次它一无所知。

PAIN — 03

云端 AI 游戏：故事不在你手里

你的角色和剧情存在别人的服务器上，随订阅涨价、随关服归零；中文语境隔一层机翻，代入感先天不足。

孤独世界把「无限剧情的 AI」装进「会记事的本地引擎」——
世界由你共创，记忆归你保管，故事永远在你自己的硬盘里。

03 · 核心价值

会记事的引擎，才配得上无限剧情

每一项特性都在回答同一个问题：如何让一段由 AI 生成的故事，值得你投入三个月。

NO-SCRIPT

无预设剧情

没有主线任务清单，没有既定故事线。你推开门，故事才发生——智能体即时即兴，回应你的一切胡来。

CO-CREATE

世界观共创

开局 5 轮问答：时代、地点、人物、社会风貌。世界不是随机生成的背景板，是按你的想象搭起来的舞台。

MEMORY

角色长期记忆

物品、技能、性格与恩怨全部持久化存档。Token-aware 动态上下文 + 自动记忆压缩，长剧情也绝不「失忆」。

STORY.MD

文学续写（可选）

开启后，每轮互动自动生成文学化续写并写入 story.md。你在玩游戏，也在合著一部小说。

BYO-MODEL

多模型自由接入

OpenAI、Anthropic Claude、Ollama / vLLM 等任何 OpenAI 兼容接口。一个参数切换，永远不会被某家模型锁定。

CLI + WEB

终端与浏览器双形态

CLI 有终端的仪式感；Web UI 支持多用户独立存档、流式对话、Markdown 渲染。同一套存档体系，两种玩法。

05 · 快速上手

从安装到推门，不到三分钟

时间花在故事上，而不是配置上——这是我们对「上手体验」的唯一标准。

01

安装

一行命令，来自 PyPI。无需克隆仓库、无需编译。

$ pip install lonely-world

首次启动有引导：填入 API Key、Base URL 与模型名。Key 自动存入系统钥匙串，明文落盘只是兜底。

07 · 常见疑问

在你按下回车之前

Q1游戏本身收费吗？我需要花多少钱？＋
项目 MIT 协议开源，永久免费。你只需为自己使用的模型 API 付费（通常一次游玩几美分）；接入 Ollama / vLLM 本地模型则完全零成本。
Q2我不会命令行，能玩吗？＋
可以。安装 Web 版（pip install "lonely-world[web]"）后运行 lonely-world-web，浏览器打开 localhost:7860，点选或创建角色即可开始，全程图形界面。
Q3支持哪些模型？一定要用 OpenAI 吗？＋
不需要。任何 OpenAI 兼容接口都可以：OpenAI、Anthropic Claude、以及 Ollama / vLLM 跑的本地模型。用 --provider 参数或环境变量切换，随时换模型不换存档。
Q4我的存档和数据安全吗？＋
所有数据保存在你电脑的 local/ 目录，不经过任何第三方服务器（仅与你配置的模型 API 通信）。API Key 优先存入系统密钥环；故事可随时导出为 Markdown，完全可携带。
Q5玩久了 AI 会「失忆」吗？＋
这正是孤独世界的核心工程：Token-aware 动态上下文截断 + 自动记忆压缩归档。长剧情下关键设定与人物恩怨会被归档保留，而不是被直接截断丢弃。
Q6AI 写出了我不想要的走向，怎么办？＋
输入 undo（或「撤回」）即可撤销上一轮输入并恢复到之前的状态，世界会当作什么都没发生过。你的故事，你有最终剪辑权。
