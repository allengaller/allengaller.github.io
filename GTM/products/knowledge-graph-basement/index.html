The problem

You've written a thousand notes.
You've re-read three.

Every Markdown vault quietly accumulates structure — wiki-links, clusters, hubs, orphans. Almost no tool surfaces it, so your knowledge base behaves like a warehouse: everything is in there, and you can't see any of it.

01

Folders hide structure

Search only finds what you already remember to look for. The connection between two ideas stays buried until you happen to open both files.

02

Graph views are eye candy

Pretty constellations you can't query, share, or act on. You zoom in, shrug, and close the tab. Nothing about your writing changes.

03

Your LLM is flying blind

RAG chunks prose but throws away structure — how concepts link is exactly the context an agent needs to answer like you, not like a search engine.

The structure already exists — it's in your wiki-links. Nothing renders it usefully. Until now.

How it works

Three commands. Zero config.

i

Point

FAQ

The questions you'd ask.

Does my data leave my machine?+

No. Indexing and rendering are 100% local. The output is plain static files — you host them wherever you want, or don't host them at all. There is no account, no telemetry, no phoning home.

Is it Obsidian-only?+

No — any Markdown folder works. The indexer reads wiki-links, frontmatter dates and headings. Obsidian vaults, LLM-wikis, digital gardens and plain note folders all work out of the box; no plugins to install.

How big can my corpus be?+

The public demo runs on 226 real notes and the pipeline is comfortably fast there. The roadmap moves the index to SQLite + FTS5, with a design target of 10k+ documents. Huge corpora get incremental indexing first.

What does it cost?+

The core is MIT open source, forever — clone it and run it today at zero cost. The paid Cloud plan is for people who want auto-rebuild, custom domains and zero setup. Early-bird pricing is locked for waitlist members.

Where's the agent part?+

On the roadmap, deliberately after the visualization foundation: natural-language queries over your graph and a graph-of-thoughts view where the agent's reasoning chain becomes a visible whiteboard — Claude API with a local Ollama fallback.

Can I use it today?+

Yes, if you're comfortable with git and npm — clone the repo and run three commands (see "How it works"). The four MVP1 views are live. Everyone else: join the waitlist and you'll get the hosted version the week it ships.
