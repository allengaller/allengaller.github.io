01 · THE PROBLEM · 为什么需要它

想玩得好，
却总在四五个 App 之间打转。

现有的本地生活平台为「交易」而生，不为「探索」而生。越是垂直、越是小众的场景，信息越是稀碎、过时、不可信。

01

长尾场景没人管

密室、剧本杀、KTV、二次元周边、心理咨询、殡葬服务……大平台只覆盖「能抽佣」的品类，长尾场景只能靠零散帖子碰运气。

02

信息过时无标注

收藏的店去年就关门了，攻略里的价格停留在三年前。没有任何平台告诉你「这条信息最后一次核实是什么时候」。

03

排名被广告污染

竞价排名、探店软文、刷量点评——你看到的顺序，是商家付钱的顺序，不是真实口碑的顺序。

04

跨城体验完全割裂

在上海用 A，去东京换 B，到纽约再装 C。11 座城市的信息结构互不相通，每次搬家、旅行都要从零开始。

07 · FAQ · 你可能想问

先把疑虑，
一条条摆平。

数据从哪里来，靠谱吗？+
中国城市（上海 / 杭州 / 深圳 / 香港）的数据来自 Amap 数据管道，每周自动刷新；国际城市（东京 / 纽约 / 莫斯科等）由社区人工整理维护。所有内容经过 L1/L2/L3 三级可信分级，且每篇标注来源与最后核实日期。我们不接受爬虫抓取点评平台数据。
信息会不会很快过时？+
会过时的信息，我们让它自己暴露过时：每篇指南带「最后核实」日期，读者一眼可见新旧；管道定期重刷中国城市，社区定期巡检国际城市，过期内容降级重审，而不是假装它永远新鲜。
和大众点评 / Google Maps / 小红书有什么区别？+
定位不同：它们是交易平台和流量入口，为「成交」优化；DUDE Database 是开放数据库，为「探索与决策」优化——覆盖点评类不做的长尾品类（密室、心理咨询、殡葬）、标注可信等级、零广告零竞价排名、数据整体开源可 fork。
可以商用吗？+
可以。MIT 许可意味着你可以自由复制、修改、商用、再分发，只需在分发时保留版权与许可声明。给产品接数据、做city-walk手册、训练机器人，都欢迎。
我想补充自己的城市 / 常去的店，怎么参与？+
三步：Fork 仓库 → 按 真实场所模板.md 写一篇（附核实信息与日期）→ 提 PR。CI 会自动检查文件结构，CONTRIBUTING.md 里有完整指引。核验清单确保每一篇都达到 L1 标准。
为什么完全免费？你们靠什么持续？+
因为开源本身就是我们的增长策略：数据库是典型的社区共建产品，内容越多越有用，越有用越多人贡献。纯静态架构意味着接近零的托管成本，社区贡献即是内容的持续供给。
