SEC 02

市场与时机:为什么是现在

GTM 的第一步不是「我们想卖什么」,而是「市场正在为什么买单」。

WHY-1

钱在进场

美国播客广告已是 20 亿美元量级(IAB 口径※);中文品牌播客自 2023 年起密集上线,品牌预算正从「试水」转向「常规投放」。有投放,就有选台与对标需求。

WHY-2

人到场

中文播客听众为亿级规模(各方口径不一※),集中于高学历高线城市;从业者、研究者与内容专业的学生数量同步膨胀——他们都需要「看清赛道」的底稿。

WHY-3

数据缺位

听众数据锁在平台手里,行业没有一份公开、结构化、可核查的「节目级」语料;研究靠散点截图、口头相传与一次性报告。这是明确的供给空位。

位置判断

越是热钱多、从业者新的市场,越需要一份中立的底稿。We are not another chart — we are the working paper.

※ 待核实 — 涉及市场规模与听众数据的具体数字,launch 前须以 PodFest China 年度报告与 IAB 广告收入报告原文核准后方可对外引用。本页遵守仓库第一原则:只写确凿事实。

SEC 03

定位:一句话说清我们是谁

采用 Geoffrey Moore 定位模板。这句话决定官网第一屏、路演第一页、自我介绍第一句。

对于播客策划 / 品牌操盘 / 内容研究者,
他们需要在上新、投放与研究之前,快速看清一个赛道,
Podcast Database 是一个开放的中英双语播客研究语料库,
它把头部播客整理成标准化、可检索、持续更新的节目档案。
不同于平台榜单与一次性行业报告,
它逐档核查、开源可复用、按批次持续维护。

SEC 07

产品化与定价:open-core 三层

免费层负责信任与获客,付费层收「结构、检索、时效与人力」的钱。价格为假设锚点,以 30 天定价访谈回填。

TIER 1 · FREE

开放语料库

¥0 / 永久

目标:信任与获客 · 面向 P1 / P3

  • GitHub 全量 Markdown 语料
  • 19 条赛道分类浏览
  • 批次更新日志 + 字段规范
  • 模板复用,社区 PR 共建
承诺:永不收费的部分
TIER 2 · PRO

数据包订阅

¥49 /月 · ¥499 /年 ※假设

目标:第一批收入 · 面向 P2 / P3

  • 结构化导出(CSV / JSON)
  • 按赛道 / 语言 / 状态筛选检索
  • 周更 diff 通知(新档 / 变更)
  • 《赛道地图》高清版
主推 · 90 天内启动内测
TIER 3 · CUSTOM

定制研究

¥50,000 起 / 项目 ※假设

目标:高客单价 · 面向 P2 / P4

  • 定制赛道对标研究
  • 投放选台建议书
  • 联合报告与冠名
  • 交付:研究报告 + 讲解会
跑通一单再扩
边界红线

文本语料永久免费、可导出;收费的只是结构、检索、时效与人力。任何把免费层变差的改动,都必须先过这条红线——社区信任是这门生意的本金。

SEC 11

风险与对策:先把丑话写下来

GTM 最大的风险不是「没人来」,而是信任资产受损——它是这门生意唯一的本金。

风险等级对策
数据时效衰减,档案过时高批次维护制度 + 社区 PR 通道;档案强制携带「最近核查」字段。
事实错误损害可信度(立身之本)高TODO 机制 + 公开更正日志:错了就改、留痕、致谢纠错人。
平台 / 大厂出同类产品中公共品定位 + 社区关系是差异;深档质量与双语对照短期难复制;必要时合作共建。
变现过早反噬社区信任中执行 SEC 07 红线;前 6 个月保持纯免费,先攒信任再开付费。
版权与公平使用争议中只存事实性元数据与短评,不转载音频与原文;档案页只链出处。
维护人力断档中小批次滚动;模板 + 脚本持续降低单档成本;吸纳研究者共建分担。
