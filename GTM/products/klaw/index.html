三种方式，十分钟上线

从本地二进制到 in-cluster Helm，全部路径已被端到端验证。

本地二进制

# 一键构建前端 + 后端
make build
# 配置后运行
./klaw
# http://localhost:8080

Docker

docker build -t kudig-io/klaw:latest .
docker run -d -p 8080:8080 \
  -e KLAW_API_TOKEN='your-token' \
  kudig-io/klaw:latest

kind + Helm

kind create cluster \
  --config deployment/kind/cluster-config.yaml
helm upgrade --install klaw helm/klaw \
  -n klaw --create-namespace --wait
