[07] GET STARTED

三步，把 Demo 带进会议室

按客户场景检索

opendemo search 关键词 + 技术栈过滤，秒级定位匹配客户业务的案例。

拉到本地跑起来

opendemo get 拉取后照 README 启动；每个模块自带测试，演示前先本地彩排。

二开或让 AI 新做

POC 场景直接在骨架上改业务逻辑；opendemo new 可按模板生成全新演示。

terminal — opendemo-clizsh
