# GTM — FightBrain Go-to-Market 策略

**V1.0 · 2026-08**

> 循证脑科学工作台（Evidence-Based Brain Workspace）—— 以开源 PLG 为引擎、循证内容为护城河，90 天建立品类心智。

## 查看

直接用浏览器打开主策略页面：

```
GTM/index.html
```

单文件、无构建依赖，也可以直接双击在本地打开。

## 页面内容（GTM 最佳实践结构）

| # | 板块 | 回答的问题 |
|---|------|-----------|
| 01 | 产品快照与品类定义 | 我们卖什么？用户拿我们和谁比？ |
| 02 | 市场分析与时机 | 市场多大？为什么是现在（TAM / SAM / SOM）？ |
| 03 | 目标客户 ICP + Personas | 先服务好谁？痛点、场景、渠道、付费信号 |
| 04 | 定位与信息 | 定位声明（April Dunford 五要素）、三大信息支柱、电梯陈述 |
| 05 | 竞争格局与护城河 | 能力矩阵对比 + 三条护城河 |
| 06 | 定价与打包 | Free / Pro / Team，为什么免费层不阉割 |
| 07 | 渠道与分发 | 内容飞轮回路 + 渠道优先级表 |
| 08 | 发布计划 | Phase 0–3（90 天），每阶段带退出门槛 |
| 09 | 增长指标 | 北极星指标、AARRR 漏斗目标、四条护栏指标 |
| 10 | 风险与应对 | 概率 × 影响矩阵，产品结构级应对 |
| 11 | 30 天行动清单 | 10 件可勾选的事 |

## 使用约定

- 所有市场规模、竞品定价、转化率数字均为**方向性假设**，正式引用前需用真实数据校准。
- 每月复盘一次，版本号随修订递增；重大策略变更更新 Hero 区 TL;DR。
- 竞品对比维度定义：● 完整具备 / ◐ 部分具备 / ○ 不具备。
