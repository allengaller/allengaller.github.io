## 查看

直接用浏览器打开 [`index.html`](index.html)，或：

```bash
open GTM/index.html
```

页面为单文件、零依赖（仅 Google Fonts CDN，离线时自动降级为系统衬线/等宽字体），支持打印/导出 PDF（`@media print` 已适配）。
