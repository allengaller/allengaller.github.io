范围红线（先于一切结论）

  1. 只有 novel/ 下的原创作品可以进入市场化评估（《暗室》《棒棒》《娄嫂》《江城肉文二十五》《泰德》《第一次交换》《空房》《请帖》等）。
  2. resource/ 的任何内容永不发布、永不打包、永不商业化。该目录是第三方版权作品的抓取池，仅限仓库内部研究用途；对外分发即构成盗版，法律风险完全不可接受。
  3. 《Saver》（基于《遥远的救世主》的改编）在取得原作品授权前不具备商业化资格，市场分析中仅作参考项，不计入可售资产。

  5. 本仓库保持 Private。未来的发布层（网站、账号、收款）与本仓库物理隔离，不共用身份与基础设施。
  6. 本目录所有文档是决策支持材料，不构成法律意见；涉及法务、支付、税务的结论执行前须咨询相关专业顾问。

三个基本判断

  1. 资产成立，但规模有限。完本库存 7 部长篇/合集（《暗室》《棒棒》《娄嫂》《江城肉文二十五》《标价》《渡城肉文五十》，及唯一非露骨的《第二场婚礼》）加 4 部完结中短篇（《泰德》《第一次交换》《空房》《请帖》），题材覆盖主流口味（家庭禁忌、NTR、现实主义、借种/三人关系），储备足以支撑"单作品试点 → 系列化订阅"的路径，但不足以支撑平台化运营。
  2. 瓶颈在渠道与支付，不在内容。中文成人文学的读者基本盘长期存在，但合规分发被三件事卡死：平台政策、支付通道、法律辖区。GTM 的主要工作量应花在渠道尽调上，而不是继续扩充内容。
  3. 合规是前置条件，不是后补项。本仓库题材敏感度高于成人内容行业的平均水平，任何一步"先上线再打补丁"的做法都会把整个项目置于不可逆的风险中。因此路线图把合规底座列为第一阶段且设有硬性验收标准。

合规与发布边界

一、硬性红线（永久有效）

  • [ ] 只发布 novel/ 原创作品；resource/ 的任何文本、片段、改编永不发布或商用（第三方版权）。
  • [ ] 《Saver》未经原作者（权利人）书面授权不得商用——它是受版权保护作品的改编。
  • [ ] 所有角色均为成年虚构人物；任何发布版本保持这一设定，且不得出现模糊年龄表述。
  • [ ] 不面向中国大陆运营：不做大陆定向推广、不提供大陆可用的支付路径、不做规避访问限制的部署。

三、账号与身份安全

  1. 笔名矩阵：作者笔名、平台账号、邮箱、社媒全部独立于真实身份；不跨用。
  2. 基础设施隔离：发布用设备/浏览器环境与个人日常环境分离；不共享照片素材、写作习惯之外的任何个人信息。
  3. 应急预案：预设"账号被封 / 身份被关联 / 平台政策突变"三种情形的响应动作（停更、迁移、发公告的先后顺序），写在 路线图 的风险登记表中。

四、年龄门槛与内容分级

  • 发布面（无论平台还是自建站）必须有进入前的成年确认门槛；自建站场景按目标市场法律可能要求更强的年龄验证（Age Verification 立法在多个辖区持续加严，以最新法规为准）。
  • 内容页统一标注"成人内容 · 仅限 18 岁以上 · 所有角色均为成年虚构人物"声明。

五、法律与专业顾问

三、收款与主体

  1. 收款主体与真实身份隔离：用笔名 + 独立邮箱 + 独立支付账户运营；身份证件只按平台与收单方的法定要求提供给必要方，不出现在任何内容或社群场景。

市场与读者分析

一、品类定义

  • 品类：中文成人情色文学（网络文学子类），以长篇连载与中短篇合集为主要消费形态。
  • 供给格局：供给端高度碎片化——海外中文成人文学站（论坛帖、聚合站）以免费 + 广告模式为主，质量参差；付费端由订阅平台（会员制）与个人创作者主页构成，成熟品牌极少。"高完成度、有工程化管理、风格统一的原创长篇"是稀缺供给，这是本库的相对优势。
  • 需求特征：题材偏好高度圈层化，读者按标签（家庭禁忌、NTR、现实主义等）聚合，跨圈层流动弱；对"完本"的信任度高，烂尾是付费的最大心理障碍。

二、支付现实（本项目最大的硬约束）

  1. 卡组织分类：Visa/Mastercard 将成人内容列为高风险类目，常规商户通道申请会被拒；可用的是高风险收单服务商，费率高、预留金（rolling reserve）常见。
  2. PayPal 明文禁止成人内容相关交易，不可列入方案。
  3. 加密货币收款技术上可行，但带来合规、退款与用户门槛三重新问题；如采用，只作为附加选项而非主通道，且需当地法律许可。
  4. 结论：渠道选择的实质是支付通道选择。哪个平台能稳定给成人文字创作者结算，哪个平台就排第一优先级——平台流量反而是次要因素。

市场 态势 处置
中国大陆 制作、传播淫秽物品属刑事犯罪 永久排除：不做简中大陆定向运营、不建面向大陆的支付与访问路径；这一点写入合规红线
海外华人市场（东南亚、北美、欧洲等） 多数辖区成人内容对成年受众合法，但Age Verification立法（如美国部分州、英国等）持续收紧 目标市场；发布面必须带年龄门槛，并按目标国最新法规核实
其他 — 新增任何辖区前，先经合规核对清单再扩

四、平台尽调清单（启用任何平台前逐项填写）

对每个候选平台建立一份尽调记录（建议放 GTM/尽调/<平台名>.md）：

  • [ ] 当期成人内容政策原文链接与关键条款摘录（文字类是否明确允许）
  • [ ] 实名要求：账号实名与收款主体能否与真实身份隔离（不可隔离 → 否决）
  • [ ] 结算：支持的提现国家/币种、费率、预留金比例、封号先例
  • [ ] 封号风险：同类创作者被处理的公开案例（搜平台名 + adult policy enforcement）
  • [ ] 数据与迁移：能否导出读者关系与订阅名单（避免被平台锁死）
  • [ ] 退出成本：若平台政策转向，内容与读者资产的迁移路径

否决条款（一票否决）：要求非匿名实名、禁止成人文字、结算无法到达可合法持有的账户、要求上传政府身份证件至平台。

五、阶段结论

  • 试点期：订阅平台 1 个 + 匿名引流面若干，不自建站。
  • 扩张期：出现稳定现金流后再评估自建站 + 高风险收单。
  • 永久不做：面向大陆运营、发布 resource/、未授权发布《Saver》。
