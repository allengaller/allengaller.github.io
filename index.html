开场 · Opening

这是一个个人主页。我把它当作一份长期维护的笔记——记录我在 Cloud Native、AI Tooling、知识架构三条线上正在做的事，以及为什么做。

多数站点会先放一组代表项目，然后等你滚动。我更愿意先讲清楚判断：写工具时优先考虑长期可维护性；选技术时优先考虑生产证据；做知识库时同时考虑人类读者与 Agent RAG。

如果你正在评估一次合作、招募一位工程师、或者只是好奇同一个技术领域的同行在想什么，下面的六个 station 会比 GitHub 个人页更快给你答案。

此刻 · Now

构建 Agent-native 知识工具。

具体地说，我在把 KUDIG、ResolveAgent、LeetCast 这一类工具的运行痕迹沉淀成结构化知识库，让它们既能被人类直接阅读，也能被 Agent 作为 RAG 语料检索。同步在做 FDE Scope——把售前架构师工作显性化为可执行 SOP。
