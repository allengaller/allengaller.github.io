01 · WHY NOW

市场与时机

好产品进错时机等于没有产品。三个结构性变化，让「便宜、可见、开源」的冥想硬件第一次成为一门成立的生意。

趋势一

冥想从 App 走向硬件

冥想 App 订阅疲劳显现——用户付费的是「引导」，但坚持不下去缺的是「反馈」。EEG 头环品类已验证付费意愿（Muse 累计销量达百万台量级），但价格与佩戴门槛把大多数人挡在门外。

趋势二

生理数据的民主化

手环和手表用十年时间教会了大众看心率与睡眠分。用户已经形成「数字化的进步感」的消费习惯，下一步自然延伸到呼吸与定力——而这恰恰是冥想练习最难自我感知的两件事。

趋势三

开源硬件生态成熟

M5Stack 等模块化硬件把感知设备的 BOM 压到 ¥200 以内，创客社区自带传播与共创能力。「不自研硬件、专注算法与体验」的轻资产路径，过去从未如此可行。

TAM · 全球

≈ $50–90 亿 / 年

全球正念与冥想市场（口径：App 订阅 + 线下课程 + 硬件设备）。

SAM · 可服务

≈ ¥10 亿 / 年

中文圈冥想付费用户 + 全球创客 / 量化自我人群的硬件支出。

SOM · 首年可获取

≈ 0.1% → 2,000 台

首年激活 2,000 台 / 售出套件 500 套。以社区渗透率倒推，不烧钱获客。

* 以上均为估算口径，用于对齐数量级而非承诺。发布前 2 周（Phase 0 退出标准之一）用最新行业报告校准一次。

02 · POSITIONING

定位与品类

我们开辟一个新品类，而不是挤进旧品类。品类名：冥想感知硬件（Meditation Sensing Hardware）——不是「智能头环」，也不是「冥想 App 的硬件版」。

对于
想要坚持冥想、却始终得不到反馈的练习者与创客；
小观是
一款开源冥想感知硬件；
它
用麦克风与陀螺仪，把呼吸频率和身体定力变成实时可见的数据；
不同于
只会引导、无法验证练习质量的冥想 App，以及两千元起、封闭昂贵的 EEG 头环；
我们的产品
把感知算法完全开源，跑在 ¥200 的通用硬件上，所有数据留在本地。
对外一句话 「小观，把呼吸变成看得见的数据 —— 属于你自己的冥想进步记录。」
不做 · 医疗宣称不提「治疗 / 治愈 / 医疗级」，定位练习伙伴而非测量仪器。
不做 · 订阅制软件永远免费。反订阅疲劳本身即定位的一部分。
不做 · 自研硬件Phase 3 之前不碰供应链，专注算法、固件与体验。
不做 · 付费投放首期零付费广告。开源社区是唯一的获客发动机。

03 · ICP & PERSONAS

目标人群

三类核心用户，三个不同角色：初学者贡献规模，创客贡献种子与传播，老师贡献变现与背书。缺一不可，但节奏不同。

PRIMARY · 规模

「卡住的初学者」

小满 · 28 岁 · 互联网从业者

  • 试过 3 个冥想 App，没有一个坚持超过两周
  • 痛点：不知道自己「练得对不对」，缺乏进步感
  • 对数据化反馈有好感（手环 / 打卡App 重度用户）
触达 × 钩子小红书 / B 站；纯软件版零门槛体验 → 硬件升级路径
PRIMARY · 种子

「量化禅修者」

老树 · 35 岁 · 硬件工程师 / 创客

  • M5Stack 玩家，抽屉里至少三块 ESP32 开发板
  • 想要可读、可改的算法，拒绝黑盒设备
  • 既是首批用户，也是贡献者与传播节点
触达 × 钩子GitHub / B站 / 创客社区；开源算法 + 三款硬件自由刷机
PRIMARY · 变现

「冥想引导者」

陈老师 · 41 岁 · 禅修 / 瑜伽工作室主理人

  • 需要教学工具让学员「看见」自己的专注
  • 预算敏感，但愿为差异化课程体验付费
  • 自带学员网络，是最好的背书与分销渠道
触达 × 钩子行业社群 / 线下 Pilot；团体看板 + 工作室版定制
SECONDARY · Phase 2 起

海外量化自我 / Biohacker

Reddit (r/meditation · r/Biohackers)、Show HN、Hackster.io。英文 README 就绪后开放。传播价值大于直接变现，反哺 GitHub Trending。

SECONDARY · Phase 3 后

企业健康（EAP）

企业冥想课程的教具采购。等工作室模式验证后再复制，首年只记录线索、不投入资源。

我们不和冥想 App 抢「引导」，不和 EEG 抢「专业测量」。我们占住中间没人做的位置：便宜、可见、开放的练习反馈。

护城河

开源不是让出护城河，开源就是护城河

代码可被复制，但四样东西抄不走：社区与共创速度（贡献者改进算法）、品牌与东方美学、外壳与成品体验（Phase 3）、以及「数据属于你」的信任资产。我们大方地被抄袭，因为抄袭者替我们教育了品类。

诚实边界

明确说出我们不擅长什么

感知精度不及医疗设备，也不追求达到；对嘈杂环境（电视 / 说话）的鲁棒性有限。在 FAQ 与文档中主动公开算法边界——诚实本身就是与「伪科学竞品」最大的差异。

05 · MESSAGING

叙事与信息

信息屋（Message House）：一个屋顶、三根支柱、一块地基。所有对外内容——README、小红书笔记、视频脚本——都必须能回溯到其中一根支柱。

核心信息 · ROOF
冥想最难的是「看不见进步」。
小观把呼吸与定力变成数据，让每一次练习都被看见。
支柱 ①

看得见的进步

实时呼吸曲线、0–100 定力评分、历史趋势。坚持不再靠意志力，靠反馈回路。

证据：WiFi 看板实拍 / 30 天趋势对比图
支柱 ②

数据属于你

无云端、无订阅、无遥测。设备自建热点，数据只存在你的局域网和 SD 卡里。

证据：架构文档 SoftAP 设计 · 隐私声明
支柱 ③

开源、可玩、可信

MIT 协议、算法透明、三款硬件 + 纯软件版。它不骗你，因为你可以读它的每一行代码。

证据：GitHub 仓库 · validate_breath.py 验证脚本
地基三款 M5Stack 硬件已适配 呼吸算法模拟验证 7/8 通过 4 级功耗管理 · 续航 13h+ MIT 开源协议
对谁说说什么（一句话）绝不说什么
对初学者「不是你不适合冥想，是你从没看见过自己的进步。」不谈参数、协议、刷机
对创客「一个跑在 M5Stack 上的开源感知算法，欢迎来改。」不谈心灵成长、生活方式
对冥想老师「让学员第一次亲眼看见专注长什么样。」不替代老师，只做教具
对量化玩家「你的呼吸 bpm 和定力分，第一次归你自己所有。」不做医疗 / 健康声称

语言红线：不说「治疗/治愈/医疗级」；不贬低任何宗教修行传统；精度数值未经实测前绝不承诺。

06 · BUSINESS MODEL

商业模式

开源 + 硬件的双层结构：免费层做分发与信任，增值层（外壳、成品、B2B 服务）做收入。软件永远免费是铁律。

TIER 0 · 获客入口
Free

纯软件版

companion.py 桌面陪伴程序。电脑麦克风 + 摄像头即可体验核心算法，是漏斗的最顶端。

TIER 1 · 社区主力
BOM ≈ ¥100–250

开源自装

固件免费开源，用户自购 M5Stack 现货刷机。我们不赚硬件差价，赚的是社区。

TIER 2 · Phase 3 · 规划
¥399–599

官方成品套件

含冥想专用 3D 外壳、开箱即用固件、包装与说明册。毛利承担品牌与运营。

TIER 3 · B2B · 高毛利
定制报价

工作室 / 团体版

多设备 + 团体实时看板 + 课程素材包。以 Pilot 验证后定价，是收入的第二曲线。

原则一 硬件不亏钱卖，不做补贴换规模 原则二 软件与固件永久免费、永久开源 原则三 增值在外壳 / 服务 / 品牌，而非代码保密 原则四 B2B 在 C 端口碑成立之前不发力

10 · RISKS

风险与对策

把最大的风险写在最前面，并提前给出对策。风险不回避，对策要具体到动作。

风险概率 · 影响对策
呼吸检测精度被质疑，「数据不准」的口碑会杀死感知类产品高 · 高发布 validate_breath.py 验证脚本与测试数据集；邀请 KOL 盲测并公开结果；文档明示算法边界（安静环境为前提）；把「诚实边界」做成品牌资产而非遮掩。
品类教育成本高：「冥想为什么要硬件？」中 · 高定位为 App 的互补而非替代（「App 引导，小观验证」）；首发切创客圈层——他们不需要品类教育；用「看见进步」的对比内容做教育。
M5Stack 单一硬件依赖：供货波动或涨价中 · 中与 M5Stack 建立官方合作锁定货源；算法层保持平台无关，随时可扩展到通用 ESP32 板卡——这正是开源架构的战略价值。
被抄袭 / 白嫖：代码被拿去做闭源商业产品高 · 中接受并利用：开源即分发，抄袭者替我们教育品类；护城河放在品牌、外壳设计、迭代速度与社区；MIT 协议下大方授权，换取社区忠诚。
发布热度不可持续：Trending 一周后流量归零高 · 中Phase 2 内容引擎 + 挑战赛接住流量；Waitlist 与微信群在 Phase 0/1 沉淀私域；把「发布」重新定义为「90 天节奏」而非「一天事件」。
增长压力与隐私承诺冲突（想加遥测 / 云账号）低 · 高写入设计原则：无遥测不可妥协；用代理指标体系（Release 下载、自报、问卷）支撑决策；任何云功能必须本地优先、可选加入。
