# GTM —《大模型全栈实战指南》上市作战简报

单页 Go-to-Market 战略简报：[index.html](./index.html)（纯 HTML/CSS/JS，无依赖，浏览器直接打开即可）。

## 页面结构（GTM 标准实践框架）

| 章节 | 内容 | 回答的问题 |
|------|------|-----------|
| 01 市场洞察 | TAM / SAM / SOM 漏斗 + 三大趋势 | 战场在哪、多大 |
| 02 目标客户 | 3 类 ICP 画像 + JTBD | 卖给谁 |
| 03 定位与信息 | 定位声明、竞品对比表、信息屋（Message House） | 凭什么赢 |
| 04 定价与包装 | 三档阶梯定价 + 锚定逻辑 | 什么价 |
| 05 渠道与分发 | 五大渠道矩阵（角色 / 动作 / KPI） | 走哪条路 |
| 06 发布节奏 | T-60 → T+90 六阶段时间轴 | 什么时候打 |
| 07 增长模型与度量 | AARRR 漏斗、北极星指标、护栏指标 | 怎么算赢 |
| 08 风险与预案 | 风险矩阵 + 四项预案 | 先想败局 |
| 09 执行清单 | 90 天 12 项按周排期清单 | 落到下周 |

## 使用说明

- 页面中的市场规模、KPI、价格均为**战略基线假设**，用于统一团队作战语言，上线前应替换为真实调研与历史数据。
- 交互：滚动进度条、导航高亮、数字滚动、漏斗/ TAM 条生长动画（纯 CSS + 少量原生 JS）。
- 字体经 Google Fonts 加载（Noto Serif SC / Noto Sans SC / IBM Plex Mono），离线打开会回退到系统字体，内容不受影响。
